MEETING HUB v5.1 — ОБНАРУЖЕНИЕ И ЗАПИСЬ ВСТРЕЧ

Установка
1. Распакуйте архив в новую папку (не поверх старой версии).
2. Скопируйте в новую папку свой meeting_hub_training.json из папки предыдущей версии:
   в нём ваши шаблоны встреч (например, meet.emrm.ru) и журнал. В архиве этого файла нет,
   чтобы случайно не затереть ваш. Файл от v4.9 программа сама перенесёт в новый формат,
   предварительно сделав резервную копию.
3. Один раз запустите setup.bat: он установит пакеты для записи звука (numpy, PyAudioWPatch, soundcard)
   и Ollama с моделью для анализа расшифровок.
4. Запустите run_meeting_hub.bat. Если окно не открылось — run_meeting_hub_debug.bat.
   Без пакетов записи программа тоже работает: обнаружение встреч не требует установки.


Как работает обнаружение встреч
- Встреча начинается, когда одновременно:
  1) открыто окно встречи (Google Meet, Телемост, Zoom, Teams, Webex или ваш шаблон);
  2) это же приложение использует микрофон.
  Справа внизу появится окно «Обнаружена встреча» с отсчётом 5 секунд и кнопкой «Отмена».
- Выключенный микрофон и тишина встречу НЕ завершают.
- Когда окно встречи закрыто и микрофон свободен 10 секунд, появится вопрос
  «Встреча закончилась?». Если не ответить, режим встречи снимется через 30 секунд.
  «Нет, встреча идёт» — программа больше не спрашивает, пока встреча снова не станет активной.
- Если браузер использует микрофон в незнакомом окне (например, корпоративный сервис встреч),
  программа спросит «Это встреча?». Ответьте «Да», отметьте «Запомнить окно встречи»,
  выберите окно и оставьте в шаблоне узнаваемую часть заголовка без кода комнаты.
  В следующий раз встреча включится сама.
- Кнопки «Начать встречу» и «Завершить встречу» работают всегда и главнее автоматики.
- Во время встречи локальный ИИ-анализ приостанавливается, после встречи запускается снова.

Запись встречи
- Если стоит галочка «Записывать встречи», запись начинается вместе с режимом встречи
  (об этом сказано в окне отсчёта) и сохраняется, когда встреча закончилась.
  Тишина после ухода со встречи (время ожидания ответа «Встреча закончилась?») из записи убирается.
- Кнопка «● Записать» / «■ Остановить запись» включает и выключает запись вручную в любой момент.
- Во время записи в строке статуса: «● ЗАПИСЬ 0:12:34» и уровни звука «вы ▮▮▮▯▯ · собеседники ▮▮▯▯▯».
  Если уровень «вы» всё время пустой — проверьте микрофон по умолчанию в Windows.
- Файл: recordings\ГГГГММДД_ЧЧММСС.wav рядом с программой, 16 кГц.
  Левый канал — ваш микрофон, правый — звук компьютера (собеседники).
  Час встречи ≈ 230 МБ. Если на диске меньше 300 МБ, запись не начнётся (будет сообщение).
- Если программа закрылась аварийно, при следующем запуске запись будет восстановлена.
- Вкладка «Записи»: список записей, «Воспроизвести», «Открыть папку».
- Записываются устройства, выбранные в Windows по умолчанию (микрофон и динамики/наушники).
- Предупреждайте участников встречи о записи.

Вкладка «Обучение»
- Журнал решений: кто принял решение (автоматика или вы), переход и причина.
- «Решение ошибочное…» для ложного старта предложит сохранить исключение,
  чтобы это окно больше не принималось за встречу.
- «Встреча пропущена…» — выбрать окно, в котором шла встреча, и сохранить шаблон.
- «Шаблоны встреч…» — список встроенных и ваших шаблонов и исключений.
- Экспорт / импорт JSON. История v4.9 хранится без изменений и видна в журнале как «v4.9 (архив)».

Конфиденциальность
- Для обнаружения встречи звук не используется: только заголовки окон и отметка Windows
  о том, какое приложение сейчас держит микрофон.
- Записи никуда не отправляются. Все данные хранятся рядом с программой. Журнал meeting_hub.log ограничен 4 файлами по 512 КБ.

Ограничения
- Запись проверена автотестами на поддельных устройствах и на Windows в GitHub Actions
  (без звуковых карт); на вашем компьютере с реальным микрофоном ещё не проверялась.
- Заголовок окна браузера показывает только активную вкладку. Если во время встречи
  переключиться на другую вкладку и выключить микрофон, через 10 секунд появится вопрос
  «Встреча закончилась?» — ответьте «Нет, встреча идёт».
- Если во время записи сменить устройство по умолчанию (подключить наушники), запись продолжит
  писать с прежнего устройства. Переключайте устройства до начала встречи.
- Транскрипции записи пока нет — это следующий этап.

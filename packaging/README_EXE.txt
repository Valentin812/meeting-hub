MEETING HUB — ПОРТАТИВНАЯ ВЕРСИЯ (без установки)

Рекомендуется установщик MeetingHubSetup-vX.exe: он ставит программу в постоянную папку,
создаёт ярлыки и обновляется поверх. Эта ZIP-версия — для запуска без установки (например, с флешки).

Запуск
1. Распакуйте архив в постоянную папку, например C:\MeetingHub.
2. Запустите MeetingHub.exe. Если Windows покажет «Windows защитила ваш компьютер» —
   «Подробнее» → «Выполнить в любом случае» (пока программа не подписана сертификатом).
3. Откроется мастер настройки: он проверит запись, подскажет, что делать, если её что-то блокирует
   (например, Kaspersky), и перенесёт данные из прежней версии.
4. Для анализа расшифровок через Ollama один раз запустите setup_ollama.bat.

В портативной версии все данные хранятся в этой же папке (файл portable.txt включает этот режим):
- recordings\ — записи встреч (левый канал — вы, правый — собеседники);
- meeting_hub_training.json — шаблоны встреч и журнал решений;
- meeting_hub.log — технический журнал;
- папку _internal не трогайте — это сама программа.

Если запись не работает: вкладка «Записи» → «Мастер настройки…» или «Отчёт для поддержки…».

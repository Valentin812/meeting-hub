MEETING HUB v5.2 — ГОТОВАЯ ПРОГРАММА ДЛЯ WINDOWS (MeetingHub.exe)

Python и пакеты устанавливать НЕ нужно: всё уже внутри папки.

Установка
1. Распакуйте архив в новую папку, например C:\MeetingHub.
2. Скопируйте в эту папку (рядом с MeetingHub.exe) свой meeting_hub_training.json
   из предыдущей версии — там ваши шаблоны встреч (meet.emrm.ru) и журнал.
3. Запустите MeetingHub.exe. Windows может показать «Windows защитила ваш компьютер» —
   нажмите «Подробнее» → «Выполнить в любом случае» (программа не подписана сертификатом).
4. Для анализа расшифровок через Ollama один раз запустите setup_ollama.bat.

Проверка записи
- Вкладка «Записи» → «Проверить запись (5 с)»: говорите и включите видео.
- Если ошибка: «Подробная проверка звука…» или audio_check.bat → пришлите meeting_hub_audio_report.txt.

Где что лежит (всё рядом с MeetingHub.exe)
- recordings\ — записи встреч (WAV, левый канал — вы, правый — собеседники);
- meeting_hub_training.json — шаблоны встреч и журнал решений;
- meeting_hub.log — технический журнал;
- папку _internal не трогайте — это сама программа.

Подробности о работе обнаружения и записи — в README.txt.
